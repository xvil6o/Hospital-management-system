# Hospital management system cpp

Console-based application to manage hospital patients, appointments and doctors.

## Features
- Add new patient/doctor
- Book/cancel an appointment 
- View patients records
- Search by ID or name
- Save/load data to/from file (using fstream)
- Input validation
- Bill calculation 

## Technologies
- C++
- STL: vector, string, fstream, etc.
